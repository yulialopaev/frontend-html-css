
Селекторы в CSS — это правила, которые указывают браузеру, к каким именно HTML-элементам нужно применить стили. Их много: от самых простых (по имени тега) до супер-современных «умных» селекторов.

Давайте разберем **абсолютно все группы селекторов** с наглядными примерами.

---

### ## 1. Базовые селекторы (Basic Selectors)

Это фундамент, который используется в 90% случаев.

```css
/* 1. Универсальный селектор — выбирает ВООБЩЕ ВСЕ элементы на странице */
* {
  box-sizing: border-box;
  margin: 0;
}

/* 2. Селектор типа (по тегу) — выбирает все указанные теги */
p {
  color: #333; /* Все параграфы станут темно-серыми */
}

/* 3. Селектор класса — выбирает элементы с определенным class="" (через точку) */
.button-primary {
  background-color: blue;
}

/* 4. Селектор идентификатора — выбирает ОДИН уникальный элемент с id="" (через решетку) */
#main-header {
  font-size: 24px;
}

```

---

### ## 2. Комбинаторы (Combinators)

Они связывают селекторы между собой, учитывая то, как теги расположены друг относительно друга в HTML-дереве.

```css
/* 1. Вложенный селектор (через пробел) — выберет ВСЕ элементы B внутри A, неважно как глубоко */
div p {
  color: red; /* Выберет любые <p> внутри <div> */
}

/* 2. Дочерний селектор (через >) — выберет только ПРЯМЫХ детей. Глубже не пойдет */
ul > li {
  list-style: none; /* Только li первого уровня */
}

/* 3. Соседний селектор (через +) — выберет элемент B, который идет СРАЗУ ЖЕ за элементом A на одном уровне */
h1 + p {
  font-weight: bold; /* Только первый абзац сразу после заголовка */
}

/* 4. Общий соседний селектор (через ~) — выберет ВСЕ элементы B, которые идут после A на одном уровне */
h1 ~ p {
  color: gray; /* Все абзацы ниже h1 в этом же контейнере */
}

```

---

### ## 3. Селекторы атрибутов (Attribute Selectors)

Позволяют выбирать элементы по наличию HTML-атрибутов (например, `href`, `type`, `target`) или по их значениям.

```css
/* 1. Просто по наличию атрибута */
img[alt] {
  border: 2px solid green; /* Подсветит картинки, у которых заполнен alt */
}

/* 2. Точное совпадение значения */
input[type="text"] {
  border-color: gray;
}

/* 3. Значение НАЧИНАЕТСЯ с указанного текста (через ^=) */
a[href^="https"] {
  color: green; /* Все безопасные внешние ссылки */
}

/* 4. Значение ЗАКАНЧИВАЕТСЯ на указанный текст (через $=) */
a[href$=".pdf"] {
  background-url: url('pdf-icon.png'); /* Добавит иконку к PDF-файлам */
}

/* 5. Значение СОДЕРЖИТ этот кусок текста в любом месте (через *=) */
div[class*="card-"] {
  padding: 20px; /* Выберет и class="super-card-dark", и class="card-active" */
}

```

---

### ## 4. Базовые селекторы и их склеивание (Basic & Compound)

Классы и ID можно использовать не только отдельно, но и «склеивать» с тегами или друг с другом без пробелов. Это сужает выборку.

```css
/* 1. Выбрать ВСЕ элементы с классом .active */
.active {
  display: block;
}

/* 2. Выбрать только теги button, у которых ЕСТЬ класс .btn-primary */
button.btn-primary {
  background-color: #007bff;
}

/* 3. Выбрать элемент, у которого одновременно есть ДВА класса (без пробела!) */
.menu-item.highlighted {
  color: red; /* Выберет <li class="menu-item highlighted"> */
}

/* 4. Выбрать строго один элемент по его уникальному ID */
#main-nav {
  background-color: #333;
}

/* 5. Склеивание ID и класса — выберет элемент с этим ID, только если у него есть этот класс */
#hero-section.dark-theme {
  background-color: #111;
}

```

---

### ## 5. Комбинаторы (Combinators) с классами и ID

Комбинаторы управляют отношениями между элементами на основе их вложенности. Замена простых тегов на классы и ID делает этот инструмент невероятно мощным.

```css
/* 1. Вложенный селектор (через пробел) */
/* Выберет ВСЕ элементы с классом .btn, которые лежат внутри контейнера с ID #sidebar */
#sidebar .btn {
  padding: 5px;
}

/* 2. Дочерний селектор (через >) */
/* Выберет только те элементы .item, которые являются ПРЯМЫМИ детьми блока .grid-container */
.grid-container > .item {
  border: 1px solid #ccc;
}

/* 3. Соседний селектор (через +) */
/* Выберет блок .description, который идет СРАЗУ ЖЕ после заголовка #main-title */
#main-title + .description {
  margin-top: 10px;
}

/* 4. Общий соседний селектор (через ~) */
/* Выберет ВСЕ кнопки .btn-delete, которые идут после чекбокса .checkbox-trigger на одном уровне */
.checkbox-trigger ~ .btn-delete {
  opacity: 0.5;
}

```

### ## 6. Селекторы атрибутов в связке с классами/ID

Позволяют искать элементы по их HTML-свойствам, при этом сужая поиск до конкретного класса или ID.

```css
/* 1. Выбрать ссылки с классом .download-link, у которых есть атрибут download */
.download-link[download] {
  color: green;
}

/* 2. Найти внутри формы #login-form инпут, у которого type строго равен "password" */
#login-form input[type="password"] {
  letter-spacing: 5px;
}

/* 3. Выбрать элементы .card, у которых data-status НАЧИНАЕТСЯ с "active" (через ^=) */
.card[data-status^="active-"] {
  border-color: green; /* Выберет data-status="active-user", data-status="active-admin" */
}

/* 4. Найти элемент #profile-card, у которого ссылка на аватар ЗАКАНЧИВАЕТСЯ на ".png" (через $=) */
#profile-card img[src$=".png"] {
  border-radius: 50%;
}

/* 5. Выбрать любой элемент .box, у которого в атрибуте class СОДЕРЖИТСЯ слово "theme-" (через *=) */
.box[class*="theme-"] {
  transition: background 0.3s;
}

```

### ## 7. Псевдоклассы (Pseudo-classes)

Они выбирают элементы, основываясь на их **состоянии** (кликнули, навели мышку) или **положении** в структуре кода.

#### Поведение и состояния:

```css
a:hover { color: orange; }       /* При наведении мыши */
input:focus { outline: none; }   /* Когда внутри поля горит курсор */
button:active { transform: scale(0.98); } /* В момент самого клика */
input:disabled { opacity: 0.5; } /* Если элемент заблокирован */
:checked + label { font-weight: bold; } /* Выбранный чекбокс/радиокнопка */

```

#### Структурные псевдоклассы:

```css
li:first-child { margin-top: 0; }     /* Самый первый li в списке */
li:last-child { margin-bottom: 0; }    /* Самый последний li */
li:nth-child(2) { background: #eee; }  /* Строго второй li */
li:nth-child(odd) { background: #f9f9f9; } /* Все нечетные (1, 3, 5...) */
li:nth-child(3n) { color: blue; }     /* Каждый третий элемент (3, 6, 9...) */

/* Отрицание */
div:not(.ignore-me) { display: block; } /* Выбрать все div, кроме тех, у которых класс .ignore-me */

```

---

### ## 7.2. Псевдоклассы (Pseudo-classes) для классов и ID

Псевдоклассы работают с динамическим состоянием элементов или их позицией в коде.

#### Состояния (User Action):

```css
.btn-submit:hover { background: darkblue; }   /* Наведение на кнопку с этим классом */
#search-input:focus { width: 300px; }         /* Фокус на инпуте с этим ID */
.menu-link:active { color: gray; }            /* Момент клика по ссылке класса */
.form-field:disabled { background: #eee; }    /* Заблокированное поле класса */
#agree-checkbox:checked + .label-text { font-weight: bold; } /* Выбранный ID меняет соседний класс */

```

#### Структурные псевдоклассы:

```css
/* Важно: nth-child считает ВСЕХ детей в родителе, а не только элементы с этим классом! */
.user-list-item:first-child { border: none; } /* Самый первый элемент списка */
#gallery .photo:last-child { margin-right: 0; } /* Последнее фото внутри галереи */
.data-row:nth-child(even) { background: #f5f5f5; } /* Все четные строки таблицы */

/* Отрицание (:not) */
/* Выбрать все карточки .product-card, кроме той, у которой есть ID #featured-product */
.product-card:not(#featured-product) {
  transform: scale(0.9);
}

/* Выбрать все кнопки .btn, кроме тех, у которых есть класс .disabled */
.btn:not(.disabled) {
  cursor: pointer;
}

```

### ## 8. Псевдоэлементы (Pseudo-elements)

Они позволяют стилизовать виртуальные части элементов или создавать декоративные элементы прямо из CSS, не загрязняя HTML-код. Обозначаются **двумя двоеточиями** `::`.

```css
/* Создает виртуальный элемент ПЕРЕД содержимым */
.price::before {
  content: "$";
  color: green;
}

/* Создает виртуальный элемент ПОСЛЕ содержимого */
.link::after {
  content: " ↗";
}

/* Стилизация подсказки (placeholder) внутри инпута */
input::placeholder {
  color: #ccc;
  font-style: italic;
}

/* Стилизация первой буквы абзаца (красивая буквица) */
p::first-letter {
  font-size: 200%;
  font-weight: bold;
}

/* Стилизация текста, который пользователь выделил мышкой */
p::selection {
  background: yellow;
  color: black;
}

```

### ## 8.2. Псевдоэлементы (Pseudo-elements) для классов и ID

Позволяют стилизовать виртуальные части или создавать декоративные элементы для конкретных классов или ID (пишутся через `::`).

```css
/* Создает красивую декоративную иконку ПЕРЕД текстом элемента .is-required */
.is-required::before {
  content: "* ";
  color: red;
}

/* Добавляет стрелочку ПОСЛЕ ссылки с классом .external-link */
.external-link::after {
  content: " ↗";
}

/* Изменяет цвет подсказки (placeholder) внутри инпута #email-field */
#email-field::placeholder {
  color: #999;
}

/* Красивое выделение текста мышкой внутри блока #main-article */
#main-article::selection {
  background-color: #ff00ff;
  color: white;
}

```

### ## 9. Современные «Умные» селекторы (CSS4)

Эти селекторы значительно упрощают написание стилей и избавляют от необходимости использовать JavaScript там, где раньше без него нельзя было обойтись.

```css
/* 1. Селектор :is() — группирует селекторы, сокращая код */
/* Вместо: section h1, section h2, article h1, article h2 */
:is(section, article) :is(h1, h2) {
  margin-bottom: 10px;
}

/* 2. Селектор :where() — делает то же самое, что и :is(), но сбрасывает специфичность (приоритет) до нуля. Его легко перебить в любом другом месте кода */
:where(.card, .box) p {
  color: gray;
}

/* 3. Селектор родителя :has() — революционный селектор! Позволяет стилизовать РОДИТЕЛЯ в зависимости от того, что у него внутри */
.card:has(img) {
  padding: 0; /* Уберет паддинг у карточки, ТОЛЬКО если внутри этой карточки есть картинка */
}

.form-group:has(input:focus) {
  border-color: blue; /* Подсветит всю рамку блока, если инпут внутри него активен */
}

```

### ## 9.2. Современные селекторы (CSS4) с классами и ID

Эти селекторы делают CSS по-настоящему «умным», позволяя связывать классы и ID в сложнейшие логические цепочки.

```css
/* 1. Селектор :is() — группировка для сокращения кода */
/* Выберет ссылки .link как внутри шапки #header, так и внутри подвала #footer */
:is(#header, #footer) .link {
  text-decoration: none;
}

/* 2. Селектор :where() — то же самое, но не добавляет "веса" (приоритета) селектору */
:where(.sidebar, #content) .alert-box {
  background: red; /* Легко перебить в другом месте кода */
}

/* 3. Родительский селектор :has() — главная магия современного CSS */
/* Стилизовать карточку .user-card, ТОЛЬКО если внутри нее есть аватар с ID #vip-status */
.user-card:has(#vip-status) {
  border: 2px solid gold;
  background-color: #fffdf0;
}

/* Подсветить всю форму .login-form красной рамкой, если внутри нее есть хоть один невалидный инпут */
.login-form:has(input:invalid) {
  border-color: crimson;
}

```

# 💡 Главное правило: Приоритет (Специфичность)

Когда вы комбинируете классы и ID, помните про их "вес" в глазах браузера:

1. **ID (`#id`)** — самый тяжелый (весит 100 «очков»).
2. **Класс (`.class`)** — средний вес (весит 10 «очков»).
3. **Тег (`div`, `p`)** — самый легкий (1 «очко»).

Селектор `#sidebar .menu-item` (110 очков) всегда выиграет у селектора `.navigation .menu-item` (20 очков), даже если второй написан в файле ниже.
