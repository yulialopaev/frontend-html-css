# В CSS-переменные (официально называемые **Custom Properties** или пользовательские свойства) можно сохранить **практически любое валидное значение** CSS-свойства.

Главное правило: переменная хранит «сырое» значение (токены), и браузер подставляет его именно в том виде, в котором оно было записано, в место вызова функции `var()`.

Вот основные категории того, что можно сохранить:

-----

### 1\. Цвета (Самый частый кейс)

Вы можете хранить цвета в любом формате: HEX, RGB, HSL, или именованные цвета.

```css
:root {
  --primary-color: #ff4500;
  --text-dark: rgba(0, 0, 0, 0.87);
  --brand-blue: blue;
}
```

### 2\. Размеры и единицы измерения

Любые единицы длины, времени или угла.

```css
:root {
  --gap-size: 20px;
  --container-width: 1200px;
  --transition-speed: 0.3s;
  --rotation-angle: 45deg;
}
```

### 3\. Строки и текст

Это часто используется вместе со свойством `content` в псевдоэлементах.

```css
:root {
  --tooltip-text: "Внимание!";
}

.element::before {
  content: var(--tooltip-text);
}
```

### 4\. Составные (сложные) значения

Переменная может хранить целую строку значений, если свойство это поддерживает (например, тени, шрифты, градиенты).

```css
:root {
  /* Тень */
  --card-shadow: 0 4px 6px rgba(0,0,0,0.1);
  
  /* Семейство шрифтов */
  --main-font: "Helvetica Neue", Arial, sans-serif;
  
  /* Градиент */
  --bg-gradient: linear-gradient(90deg, red, blue);
}
```

### 5\. Числа без единиц измерения

Очень полезно для множителей (например, в `line-height` или для использования внутри `calc()`).

```css
:root {
  --line-height-base: 1.5;
  --multiplier: 2;
}

.box {
  /* Итоговая ширина будет 200px (100px * 2) */
  width: calc(100px * var(--multiplier)); 
}
```

### 6\. Ссылки на ресурсы (URL)

Можно хранить пути к изображениям.

```css
:root {
  --bg-image: url('images/pattern.png');
}
```

### 7\. Части значений (Продвинутый уровень)

Вы можете хранить не цвет целиком, а только цифры каналов RGB. Это мощный прием для динамического изменения прозрачности.

```css
:root {
  --color-rgb: 255, 0, 0; /* Только цифры красного цвета */
}

.button {
  /* Подставляем цифры внутрь rgba и добавляем прозрачность */
  background-color: rgba(var(--color-rgb), 0.5); 
}
```

-----

### ❌ Что НЕЛЬЗЯ сохранить

Есть важные ограничения. Переменная **не может** содержать:

1.  **Названия свойств:** Нельзя сохранить слово `width` или `color` и использовать его как имя свойства.
      * *Неверно:* `var(--prop-name): 20px;`
2.  **Селекторы:** Нельзя сохранить `.class` или `#id`.
3.  **Медиа-запросы:** Нельзя использовать переменную в `media (min-width: var(--bp))`.

### Итог

CSS-переменные невероятно гибки. Браузер валидирует их **в момент использования**, а не в момент объявления. Если вы сохраните в переменную "10px", а потом попытаетесь использовать её в свойстве `color`, браузер просто проигнорирует эту строку (или использует fallback-значение), так как "10px" не является валидным цветом.
